# CPU软渲染 -- 光线追踪渲染器 -- 公开课

## 课程特色
* **基于物理**的渲染
* **纯CPU**运行，专注算法原理
* 使用**C++ 17**进行开发
* 从**Hello World**开始
* 尽量避免使用C++**高级语言特性**
